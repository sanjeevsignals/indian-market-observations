## 🎓 Analysis Framework

### Pre-Analysis (Morning Plan)
- Key support/resistance levels
- Opening control framework
- Execution rules
- What to watch

### Post-Analysis (EOD Review)
- Level validation
- Price action breakdown
- What worked/didn't work
- Lessons learned

## 📊 Core Principle

> **Levels decide. Noise doesn't.**

## ⚡ How to Use This Repository

1. **Before Market Open:** Check Pre-Analysis for today's levels
2. **During Market:** Watch how price respects/violates the levels
3. **After Market Close:** Review Post-Analysis for insights
4. **Weekly/Monthly:** Study patterns across multiple days

## 🔍 File Naming Convention

**Markdown Files:**
- Pre-Analysis: `DD-Mon-YYYY.md` (e.g., `23-Jan-2026.md`)
- Post-Analysis: `DD-Mon-YYYY-post.md` (e.g., `23-Jan-2026-post.md`)

**Chart Images:**
- Pre-Analysis: `YYYY-MM-DD-index-pre.png` (e.g., `2026-01-23-nifty50-pre.png`)
- Post-Analysis: `YYYY-MM-DD-index-post.png` (e.g., `2026-01-23-nifty50-post.png`)
